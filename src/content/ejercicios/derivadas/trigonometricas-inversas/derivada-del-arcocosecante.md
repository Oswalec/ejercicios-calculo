## Enunciado

Demuestra que $\dfrac{d}{dx}\operatorname{arccsc} x = -\dfrac{1}{|x|\sqrt{x^2 - 1}}$ para $|x| > 1$.

## Solución

1. Para $|x| \ge 1$, con las definiciones usuales, se cumple $\operatorname{arcsec} x + \operatorname{arccsc} x = \frac{\pi}{2}$.
2. Entonces $\operatorname{arccsc} x = \frac{\pi}{2} - \operatorname{arcsec} x$.
3. Usando la derivada del arcosecante: $\frac{d}{dx}\operatorname{arccsc} x = -\frac{1}{|x|\sqrt{x^2 - 1}}$.

**Resultado final:** $\dfrac{d}{dx}\operatorname{arccsc} x = -\dfrac{1}{|x|\sqrt{x^2 - 1}}$
