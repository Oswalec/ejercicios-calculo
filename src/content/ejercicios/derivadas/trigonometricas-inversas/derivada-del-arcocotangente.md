## Enunciado

Demuestra que $\dfrac{d}{dx}\operatorname{arccot} x = -\dfrac{1}{1 + x^2}$.

## Solución

1. Con la definición usual ($\operatorname{arccot} x \in (0, \pi)$) se cumple $\arctan x + \operatorname{arccot} x = \frac{\pi}{2}$ para todo $x$.
2. Entonces $\operatorname{arccot} x = \frac{\pi}{2} - \arctan x$.
3. Derivamos: $\frac{d}{dx}\operatorname{arccot} x = -\frac{1}{1 + x^2}$.

**Resultado final:** $\dfrac{d}{dx}\operatorname{arccot} x = -\dfrac{1}{1 + x^2}$
