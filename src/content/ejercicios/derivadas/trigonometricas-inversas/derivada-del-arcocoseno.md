## Enunciado

Demuestra que $\dfrac{d}{dx}\arccos x = -\dfrac{1}{\sqrt{1 - x^2}}$ para $-1 < x < 1$.

## Solución

1. Para $x \in [-1, 1]$ se cumple $\operatorname{arcsen} x + \arccos x = \frac{\pi}{2}$, porque son ángulos complementarios.
2. Entonces $\arccos x = \frac{\pi}{2} - \operatorname{arcsen} x$.
3. Derivamos: $\frac{d}{dx}\arccos x = 0 - \frac{1}{\sqrt{1 - x^2}}$.

**Resultado final:** $\dfrac{d}{dx}\arccos x = -\dfrac{1}{\sqrt{1 - x^2}}$
