## Enunciado

Halla $a$ para que $f(x) = ax^3 + 2x$ cumpla $f'(1) = 11$.

## Solución

1. Derivamos: $f'(x) = 3ax^2 + 2$.
2. Evaluamos en $x = 1$: $f'(1) = 3a + 2$.
3. Igualamos: $3a + 2 = 11$, de donde $a = 3$.
4. Comprobación: con $a = 3$, $f'(x) = 9x^2 + 2$ y $f'(1) = 11$.

**Resultado final:** $a = 3$
