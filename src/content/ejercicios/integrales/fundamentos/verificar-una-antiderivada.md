## Enunciado

¿Es $F(x) = x^3 + 2x - 7$ una antiderivada de $f(x) = 3x^2 + 2$?

## Solución

1. $F$ es una antiderivada (o primitiva) de $f$ en un intervalo si $F'(x) = f(x)$ para todo $x$ del intervalo.
2. Derivamos: $F'(x) = 3x^2 + 2 - 0 = 3x^2 + 2$.
3. Coincide con $f(x)$ para todo $x \in \mathbb{R}$.
4. La constante $-7$ no afecta: cualquier $x^3 + 2x + C$ también es antiderivada.

**Resultado final:** Sí, $F'(x) = 3x^2 + 2 = f(x)$.
