## Enunciado

Calcula $\displaystyle \int \left(3\operatorname{sen} x - 2\sec^2 x\right)dx$.

## Solución

1. Como $(-\cos x)' = \operatorname{sen} x$: $\int 3\operatorname{sen} x\,dx = -3\cos x$.
2. Como $(\tan x)' = \sec^2 x$: $\int 2\sec^2 x\,dx = 2\tan x$.
3. Resultado: $-3\cos x - 2\tan x + C$.
4. Cuidado con el signo: la integral del seno es **menos** el coseno.

**Resultado final:** $\displaystyle \int \left(3\operatorname{sen} x - 2\sec^2 x\right)dx = -3\cos x - 2\tan x + C$
