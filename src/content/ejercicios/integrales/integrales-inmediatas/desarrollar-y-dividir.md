## Enunciado

Calcula $\displaystyle \int \frac{(x + 1)^2}{x}\,dx$.

## Solución

1. Desarrollamos el numerador: $(x + 1)^2 = x^2 + 2x + 1$.
2. Dividimos entre $x$ (para $x \neq 0$): $x + 2 + \frac{1}{x}$.
3. Integramos término a término: $\frac{x^2}{2} + 2x + \ln|x|$.
4. Resultado: $\frac{x^2}{2} + 2x + \ln|x| + C$.

**Resultado final:** $\displaystyle \int \frac{(x + 1)^2}{x}\,dx = \frac{x^2}{2} + 2x + \ln|x| + C$
