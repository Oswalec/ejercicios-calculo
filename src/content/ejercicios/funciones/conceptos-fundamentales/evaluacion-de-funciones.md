## Enunciado

Sea $f(x) = 2x^2 - 3x + 1$. Calcula $f(-2)$ y $f(a + 1)$.

## Solución

1. Evaluar es reemplazar $x$ por el valor dado en **cada** aparición, usando paréntesis.
2. $f(-2) = 2(-2)^2 - 3(-2) + 1 = 2(4) + 6 + 1 = 15$.
3. $f(a + 1) = 2(a + 1)^2 - 3(a + 1) + 1$.
4. Desarrollamos: $2(a^2 + 2a + 1) - 3a - 3 + 1 = 2a^2 + 4a + 2 - 3a - 2 = 2a^2 + a$.

**Resultado final:** $f(-2) = 15$ y $f(a + 1) = 2a^2 + a$
