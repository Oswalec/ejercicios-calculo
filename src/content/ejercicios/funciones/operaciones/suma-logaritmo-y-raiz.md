## Enunciado

Sean $f(x) = \ln x$ y $g(x) = \sqrt{3 - x}$. Halla el dominio de $f + g$ y calcula $(f + g)(1)$.

## Solución

1. $\operatorname{Dom} f$: $x > 0$, es decir, $(0, \infty)$.
2. $\operatorname{Dom} g$: $3 - x \ge 0$, es decir, $(-\infty, 3]$.
3. $\operatorname{Dom}(f + g) = (0, \infty) \cap (-\infty, 3] = (0, 3]$.
4. Como $1 \in (0, 3]$: $(f + g)(1) = \ln 1 + \sqrt{2} = 0 + \sqrt{2} = \sqrt{2}$.

**Resultado final:** $\operatorname{Dom}(f + g) = (0, 3]$ y $(f + g)(1) = \sqrt{2}$
